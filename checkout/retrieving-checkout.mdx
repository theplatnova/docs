---
title: "Retrieving Checkout"
slug: "checkout/retrieving-checkout"
---

Retrieve a checkout with `GET /v1/checkout/{id}`. The call needs no authentication: the payment page uses it too.

```bash
curl 'https://api.platnova.com/v1/checkout/3e584f08-6a55-4b15-a97f-364a7d21071e'
```

## What it tells you

| `status` | Meaning |
|---|---|
| `pending` | Not paid yet. A checkout never reports "failed" or "expired": an abandoned checkout stays `pending` until it disappears after 7 days. |
| `success` | Paid. `paid_at` and `payment_reference` are set. |

<Warning>
**Do not fulfil an order from this call alone.** It returns no paid amount or payment method, and it answers `404 checkout not found` once the checkout is more than **7 days** old, paid or not. Before you ship, confirm the payment with [`POST /v1/payments/verify`](/payments/verification), which works for good and returns the amount and method.
</Warning>

## Example response (paid)

```json
{
  "status": true,
  "data": {
    "id": "3e584f08-6a55-4b15-a97f-364a7d21071e",
    "url": "https://pay.platnova.com/3e584f08-6a55-4b15-a97f-364a7d21071e",
    "status": "success",
    "paid_at": "2026-10-27T16:02:11Z",
    "payment_reference": "the payment's transaction reference",
    "amount": 25000,
    "currency": "ngn",
    "email": "ada@example.com",
    "partner_reference": "order-1042",
    "source": "api",
    "payment_options": [{ "id": "bank_transfer" }, { "id": "card" }],
    "created_at": "2026-10-27T15:57:19Z"
  },
  "error": [],
  "message": "operation was successful"
}
```

## Not found

```json
{ "status": false, "data": {}, "error": [], "message": "checkout not found" }
```

with HTTP `404`: the id is wrong, or the checkout is more than 7 days old.
