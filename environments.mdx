Platnova has two environments: a **sandbox** for building and testing, and **live** for real money.

| | Sandbox | Live |
|---|---|---|
| **Base URL** | `https://sandbox.api.platnova.co` | `https://api.platnova.com` |
| **Money** | Test only | Real |
| **Keys** | Sandbox keys | Live keys, from your dashboard once your business is live |

Sandbox and live keys are separate: a sandbox key does not work on live, and a live key does not work on the sandbox. Every example in these docs uses `X-API-Key` (see [Authentication](/authentication)); swap the base URL to switch environments.

<Tabs>
<Tab title="Sandbox">
```bash
curl https://sandbox.api.platnova.co/v1/wallets \
  -H "X-API-Key: YOUR_SANDBOX_API_KEY"
```
</Tab>
<Tab title="Live">
```bash
curl https://api.platnova.com/v1/wallets \
  -H "X-API-Key: YOUR_LIVE_API_KEY"
```
</Tab>
</Tabs>

## Sandbox

<Note>
The sandbox is being brought up to date with live. Until this note is removed, some newer endpoints may answer `404` there, including payment verification and checkout refunds. Ask [support@platnova.com](mailto:support@platnova.com) for sandbox keys; test cards and simulated bank-transfer payments will be listed here when they are available.
</Note>

## Moving to live

<Steps>
<Step title="Build against the sandbox">
Create checkouts, handle `checkout.paid`, verify payments and test refunds.
</Step>
<Step title="Finish going live">
Complete business verification and pay the verification fee. See [Going live](/going-live).
</Step>
<Step title="Switch keys and URL">
Create a live API key in the dashboard, point your integration at `https://api.platnova.com`, and register your live webhook endpoint.
</Step>
</Steps>

## Webhooks

Both environments send webhooks. Register a separate endpoint (and keep a separate secret) for each.
