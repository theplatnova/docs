## Overview

Create a virtual account for a customer. `customer_id` is the `id` that [Create Customer](/api-reference/customers/create) returned, not your own reference for the customer. A `customer_id` that isn't one of your customers is refused with `400 customer was not found` before anything else (such as the BVN) is checked, and a customer that isn't `active` gets `403`. Virtual accounts allow customers to receive payments directly into their account. This endpoint creates a bank account that can be used for receiving funds.  To generate USD virtual accounts, ensure a default USD settlement wallet is set on your [dashboard settings](https://business.platnova.com/settings?section=settlements). This wallet will be billed for USD account creation fees if applicable. For NGN virtual accounts, you can optionally specify an `id_number` parameter in the request body, which corresponds to a valid BVN.
